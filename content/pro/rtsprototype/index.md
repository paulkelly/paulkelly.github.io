***Prototype for a Survival RTS Game developed Solo***<br>

---

[Code Available On GitHub](https://github.com/paulkelly/RTSPrototype)<br><br>

This prototype was developed after finishing work on Surviving the Abyss with Rocket Flair in mind.
I wanted to create a prototype for a survival city builder like They are Billions, but with the same horror atmosphere that Surviving the Abyss had.<br><br>

The project features Procedural Generation, a Grid Shader developed using Shader Graph, Building on a Grid, Unit Movement and Management, Fog of War where areas must be kept Lit and Combat.<br><br>
